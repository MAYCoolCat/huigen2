# Huigen

Набор скриптов для подготовки коротких вертикально не? Нет: горизонтальных роликов 16:9 из фотографий. Скрипт собирает несколько вариантов видео, меняет порядок кадров, добавляет текстовую цитату и, при необходимости, музыку.

В проекте два инструмента:

- `photos_to_video.py` — собирает MP4 из фотографий, накладывает цитаты и добавляет музыку.
- `fetch_media.py` — загружает изображения из Pinterest по темам «деньги» и «роскошь».

## Что понадобится

- Python 3.10 или новее.
- FFmpeg — для сборки видео.
- Ollama и скачанная языковая модель — только если хотите генерировать цитаты автоматически.
- Доступ к интернету — для загрузки фотографий и работы Ollama при сетевом размещении.

## Установка на macOS

Откройте Терминал и перейдите в папку проекта:

```bash
cd /путь/к/huigen
```

Создайте виртуальное окружение и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Установите FFmpeg:

```bash
brew install ffmpeg
```

Проверьте установку:

```bash
python --version
ffmpeg -version
```

Если Homebrew ещё не установлен, установите его с официального сайта: https://brew.sh/.

## Установка на Windows

1. Установите Python с сайта https://www.python.org/downloads/. Во время установки включите опцию **Add Python to PATH**.
2. Установите FFmpeg и добавьте папку `bin` в системную переменную `PATH`.
3. Откройте PowerShell в папке проекта и выполните:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Подготовка фотографий

Создайте папку, например `photos`, и положите в неё изображения. Поддерживаются форматы JPG, JPEG, PNG, WEBP, BMP, TIF и TIFF.

Пример структуры:

```text
huigen/
├── photos_to_video.py
├── fetch_media.py
├── quotes100.txt
├── requirements.txt
├── music/
│   ├── track1.mp3
│   └── track2.mp3
└── photos/
    ├── photo1.jpg
    ├── photo2.jpg
    └── photo3.jpg
```

Если фотографии находятся во вложенных папках, при запуске добавьте `--recursive`.

## Сборка видео

Самый простой запуск:

```bash
python photos_to_video.py ./photos
```

По умолчанию программа создаёт 10 файлов `video_01.mp4`–`video_10.mp4` в папке `videos`. Для каждого ролика выбирается свой порядок фотографий и отдельная цитата. Стандартная длительность показа одной фотографии — 0,09 секунды.

### Часто используемые параметры

| Параметр | Для чего нужен | Значение по умолчанию |
|---|---|---|
| `--count` | Количество роликов | `10` |
| `-o`, `--outdir` | Папка для готовых видео | `videos` |
| `--duration` | Сколько секунд показывать одну фотографию | `0.09` |
| `--height` | Высота видео: 720, 1080, 1440 или 2160 | `1080` |
| `--fps` | Частота кадров | `30` |
| `--fit` | Способ размещения фото: `cover`, `contain`, `stretch` | `cover` |
| `--audio` | MP3-файл или папка с музыкой | без музыки |
| `--quote` | Одна заданная цитата для всех роликов | автоматически |
| `--quotes-file` | Файл с готовыми цитатами | — |
| `--recursive` | Искать изображения во вложенных папках | выключен |
| `--jobs` | Число роликов, собираемых параллельно | `1` |

### Примеры

Сделать 5 роликов в Full HD:

```bash
python photos_to_video.py ./photos --count 5
```

Сделать видео в разрешении 4K:

```bash
python photos_to_video.py ./photos --height 2160
```

Сохранить результат в отдельную папку:

```bash
python photos_to_video.py ./photos --count 20 --outdir ./ready
```

Добавить музыку из папки `music`:

```bash
python photos_to_video.py ./photos --audio ./music
```

Использовать один конкретный трек:

```bash
python photos_to_video.py ./photos --audio "./music/track1.mp3"
```

Задать собственную цитату:

```bash
python photos_to_video.py ./photos --quote "Твоя цитата здесь"
```

Взять цитаты из файла:

```bash
python photos_to_video.py ./photos --quotes-file quotes100.txt
```

Файл с цитатами — обычный UTF-8 текст: одна цитата на строку. Пустые строки и строки, начинающиеся с `#`, пропускаются. Нумерация в начале строки допускается.

Смешать цитаты из файла и сгенерированные:

```bash
python photos_to_video.py ./photos --quotes-file quotes100.txt --mix
```

## Автоматическая генерация цитат через Ollama

Если параметр `--quote` или `--quotes-file` не указан, программа обращается к локальному серверу Ollama. Если Ollama недоступна, используются встроенные запасные цитаты.

1. Установите Ollama: https://ollama.com/download.
2. Загрузите модель:

```bash
ollama pull llama3.1
```

3. Убедитесь, что Ollama запущена. При необходимости откройте отдельное окно Терминала и выполните:

```bash
ollama serve
```

4. Запустите генерацию:

```bash
python photos_to_video.py ./photos --count 10 --topic "дисциплина и успех"
```

Можно выбрать другую установленную модель:

```bash
python photos_to_video.py ./photos --model qwen2.5:7b
```

Указанная модель должна быть предварительно загружена через `ollama pull`.

## Загрузка фотографий из Pinterest

Скрипт `fetch_media.py` ищет изображения по двум группам запросов: `money` и `luxury`.

Загрузить 40 изображений (значение по умолчанию) в папку `photos`:

```bash
python fetch_media.py ./photos
```

Загрузить 80 изображений:

```bash
python fetch_media.py ./photos --photos 80
```

Выбрать только одну категорию:

```bash
python fetch_media.py ./photos --categories money --photos 50
```

Или только изображения о роскошном образе жизни:

```bash
python fetch_media.py ./photos --categories luxury --photos 50
```

Скрипт сохраняет список обработанных идентификаторов в `.downloaded.json`, чтобы не скачивать одни и те же изображения повторно. Этот файл не нужно редактировать вручную.

Загрузка зависит от доступности Pinterest и работы сторонней библиотеки `pinterest-downloader`. Сайт может менять механизм выдачи, поэтому загрузчик иногда перестаёт работать без обновления зависимости.

После загрузки можно сразу собрать ролики:

```bash
python photos_to_video.py ./photos --count 10 --audio ./music
```

## Где искать результат

После завершения работы в папке `videos` (или в каталоге, указанном через `--outdir`) появятся:

- `video_01.mp4`, `video_02.mp4` и другие готовые ролики;
- `quotes.txt` — список цитат, использованных в каждом видео.

Если программа сообщает, что FFmpeg не найден, проверьте его установку и переменную `PATH`. Если не найден шрифт с кириллицей, добавьте файл `.ttf` в папку `fonts` рядом с `photos_to_video.py` или укажите его путь через `--font`.

## Примечания

- Для каждого ролика фотографии перемешиваются независимо.
- При использовании папки с музыкой треки распределяются между роликами без повторов, пока список не закончится.
- Итоговая длительность зависит от количества фотографий и значения `--duration`. Например, 100 фотографий при `0.09` секунды на кадр дают около 9 секунд видео.
- Используйте изображения и музыку, на которые у вас есть права или разрешение на публикацию. Наличие файла в интернете не означает, что его можно свободно использовать.
